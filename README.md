# BBARU

> 목표 도착 시각에 가장 가깝게 도착하도록 돕는 초개인화 ETA 서비스

**Live Demo: [bbaru.vercel.app](https://bbaru.vercel.app)**

기존 지도 앱은 "지금 출발하면 언제 도착하는지"를 알려줍니다. BBARU는 반대로 묻습니다 — **"그 시각에 도착하려면 언제 출발해야 하는가?"** 출근, 면접, 공연처럼 도착 시각이 중요한 상황에서 너무 늦지도, 너무 이르지도 않게 도착하도록 출발 시각 추천과 이동 중 행동 지시를 제공합니다.

| 메인 · POI 자동완성 | 경로 결과 · 실지도 | 이동 중 · 실시간 신호 |

## 핵심 기능

- **목표 도착 시각 기반 출발 추천** — 출발지·도착지·목표 도착 시각을 입력하면 권장 출발 시각과 예상 도착 시각, 현재 시각 기준 행동 상태("지금 출발 가능" / "N분 후 출발 권장" / "서둘러야 함")를 제공합니다. 자정 넘김·목표 시각 경과도 처리합니다.
- **도착 전략 3모드** — `안전 우선`(버퍼 5분) / `균형`(3분) / `정시 우선`(1분)을 실시간 비교·전환할 수 있습니다.
- **Tmap 실경로 연동** — POI 자동완성으로 장소를 고르면 Tmap 대중교통 API의 실제 경로(도보·지하철·버스 구간, 실소요·환승·요금)로 계획을 세우고, 대안 경로도 실데이터로 비교합니다.
- **GPS 실이동 추적** — 이동 중 실제 위치를 경로 폴리라인에 투영해 진행률·예상 도착·페이스 안내를 갱신하고, 경로 이탈(50m+)과 도착을 자동 판정합니다. 권한 거부·미지원·실경로 없음 상황은 정적 경로 안내로 전환됩니다(개발 모드에서는 데모 시뮬레이션 폴백).
- **실시간 보행 신호 반영** — 공공데이터포털 "교통안전 신호등 실시간 정보"로 경로 주변 교차로의 보행 신호 상태·잔여 초를 폴링해, "지금 건너세요 / N초 후 보행 신호" 같은 행동 판단을 제공합니다. 데이터 공백(심야·미제공 교차로)은 정직하게 안내합니다.
- **개인 보행 속도 보정** — 키를 입력하면 보폭 추정(키×0.415 × 1.9보/초)으로 즉시 도보 구간 소요시간을 보정하고, 이동 중 GPS 기록에서 보행 구간 속도를 수집(정확도·거리·범위 필터링)해 지수이동평균으로 학습합니다. 샘플 10개 이상부터는 실측 속도가 우선 적용되며, 적용 시 "키 기준 / 내 보행 속도 반영" 배지로 표시됩니다.
- **PWA** — 홈 화면 설치, 오토업데이트 서비스워커, 오프라인 셸.
- **최근 경로** — 검색 조건을 저장해 원터치로 재검색합니다.

## 아키텍처

```
api/                          # Vercel Functions — API 키 보호 프록시
├── tmap/{pois,transit}.ts    #   Tmap POI·대중교통 (서버 전용 키)
└── signal/{crossroads,realtime}.ts  # 신호등 공공데이터
src/app/
├── App.tsx                   # react-router 라우팅 (+ 검색 상태 가드)
├── context/RouteContext.tsx  # 검색·모드·최근 경로 상태, API 실패 시 목업 폴백
├── lib/
│   ├── eta.ts                # ETA 코어: 권장 출발/편차/상태 판정 (순수·결정적 함수)
│   ├── tracking.ts           # GPS 경로 투영·ETA 재계산·이탈/도착 판정 (순수 함수)
│   ├── geolocation.ts        # watchPosition 래퍼, 일시적 오류 분류
│   ├── enRoute.ts            # 데모 시뮬레이션 진행/신호 대기 (순수 함수)
│   ├── tmap.ts / transitMapper.ts   # Tmap 클라이언트·경로 세그먼트 매핑
│   └── signal.ts             # 신호등 파싱 + 횡단 행동 판단
└── components/
    ├── MapView.tsx           # Tmap 벡터 지도 (SDK 실패 시 목업 지도 폴백)
    └── screens/              # 메인 / 경로 결과 / 이동 중 / 디자인 시스템
```

### 설계 원칙

- **계산 로직은 전부 순수 함수** — ETA 산식, GPS 투영, 신호 파싱·행동 판단이 React 밖의 순수 모듈에 있어 실제 API 응답 픽스처로 유닛 테스트합니다 (vitest 59건 + Playwright E2E).
- **API 키는 번들에 넣지 않는다** — 모든 REST 호출은 서버리스 프록시(`api/`)를 거치고 키는 서버 환경변수에만 존재합니다. 로컬 개발은 Vite dev proxy가 같은 경로를 대신합니다. (지도 SDK 키만 브라우저 특성상 공개 — 도메인 제한 필수)
- **API 없이도 완결되는 폴백** — 키가 없거나 API가 실패(쿼터 초과 포함)하면 결정적 목업 엔진으로 자동 전환되고 "데모 데이터" 배지를 표시합니다. 지도·이동 추적도 각자 폴백을 갖습니다.
- **실데이터를 행동 지시로 번역** — 신호 잔여 초를 그대로 보여주는 대신 예상 횡단 시간과 비교해 "건너라/기다려라"로 변환합니다.

### 트러블슈팅 기록

- Tmap JS SDK 로더가 `document.write`로 본체를 로드해 동적 주입 시 지도가 뜨지 않는 문제 → index.html 정적 스크립트(+ Vite HTML env 치환) + `Tmapv3` 폴링 대기로 해결.
- `watchPosition`이 정상 위치 업데이트 사이에 일시적 오류(POSITION_UNAVAILABLE 등)를 섞어 보내 추적이 중단되던 문제 → 오류 분류(권한 거부만 치명적) + 연속 오류·무수신 시간 기준으로 해결.
- 신호등 API가 심야에 NODATA로 비고 교차로별 제공이 유동적 → 유효 신호만 선별, 공백 시 정직한 안내 + 폴링 백오프.
- Tmap 대중교통 API 무료 쿼터 소진(429 QUOTA_EXCEEDED) 시 실경로 좌표가 없어 GPS 추적 불가 → 데모 자동 전환 안내. **실서비스 전 Tmap 요금제/쿼터 증설과 공공데이터 운영계정 신청이 필요합니다.**

## 데이터 소스

| 데이터 | 제공 | 용도 |
| --- | --- | --- |
| 대중교통 경로 | Tmap Open API (`/transit/routes`) | 실경로·구간·소요시간·요금 |
| 장소 검색 | Tmap Open API (`/tmap/pois`) | 출발지/도착지 자동완성·지오코딩 |
| 벡터 지도 | Tmap JS SDK (Tmapv3) | 경로·마커·이동 위치 표시 |
| 교통안전 신호등 실시간 정보 | 공공데이터포털 (행안부 한국지역정보개발원) | 교차로 보행 신호 상태·잔여시간 |

## 실행 방법

```bash
npm install
cp .env.example .env.local   # 키 입력
npm run dev
```

`.env.local`:

```
TMAP_APP_KEY=           # 서버/프록시 전용 (https://openapi.sk.com)
DATA_GO_KR_KEY=         # 서버/프록시 전용 (https://www.data.go.kr — "교통안전 신호등 실시간 정보" 활용신청)
VITE_TMAP_APP_KEY=      # 지도 SDK 전용 (공개 키 — SK 콘솔 도메인 제한 필수)
```

키가 없어도 목업 데이터로 전체 플로우를 시연할 수 있습니다. Vercel 배포 시 같은 이름의 환경변수를 대시보드에 등록하세요.

```bash
npm test        # vitest — 엔진·매퍼·신호·추적 59건
npm run e2e     # Playwright 스모크 (키 없으면 목업 플로우 검증)
npm run build   # 프로덕션 빌드 (PWA 포함)
```

CI(GitHub Actions)는 push/PR마다 유닛 테스트 → 빌드 → 키 없는 E2E를 실행합니다.

## 한계와 로드맵

- Tmap 대중교통 무료 쿼터가 작아 실서비스에는 요금제 계약 필요, 공공데이터도 운영계정 필요
- 환승 성향(환승 횟수 선호 등) 프로필은 미반영 → 경로 선택 이력 기반 개인화 (개인 보행 속도는 이동 중 GPS 기록으로 학습·보정 반영됨)
- 신호등 실시간 데이터는 지자체·시간대별 제공 편차가 있음 (서울 기준 교차로 2,777곳 중 실시간 ~999곳)
- 경로 이탈 시 자동 재탐색 미지원 → 이탈 감지 후 재경로 계산
- 실 GPS를 수집하는 한국 서비스는 위치기반서비스(LBS) 사업자 신고·개인정보처리방침 필요 — 출시 전 확인
